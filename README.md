# BFE (Big Fucking Extruder)

This is a high performance dual nema17 extruder for bowden printers. It can keep up with demanding pressure advance values and extreme speeds and accelerations.

## FEATURES
Two nema17 motors with 17t hobs
Two pairs of LGX/HGX gears for maximum grip
Equally tensioned idlers, ensuring synchronous extrusion between the gearsets
PC4 M10 Bowden Couplers for maximum security and reduced PA

## BOM

2x Nema17 motors
2x LGX (preferred) or HGX gear sets
2x 17t stainless steel motor hob
2x PC4 M10 fittings
1x 23mm PTFE Tube (1.9mm ID preferred, e.g Capricorn)
1x 3mm ID 8-12mm length spring (standard in most extruders)
1x M3 x 50mm SHCS
8x M3 x 8mm BHCS
8x M3 washers, 6-8mm OD
2x M3 x 26mm SHCS
3x M3 hex nut
1x M3 heat set insert
2x M3 x 24mm pin
4x M3 x 16mm pin
